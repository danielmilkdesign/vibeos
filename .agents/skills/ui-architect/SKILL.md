# UI Architect Skill - Vibe OS

## Responsabilidade
- Receber requisitos visuais, mockups ou especificações de produto.
- Criar a `DESIGN_SPEC.md` detalhando variantes CVA, mapeamento de tokens e acessibilidade.
- Criar o arquivo `tasks.md` decompondo o desenvolvimento em passos atômicos executáveis por agentes de engenharia.

## Diretrizes
- Siga as regras em `file:///D:/vibe-os/SYSTEM_RULES.md`.
- Garanta que todas as variantes possíveis estejam declaradas explicitamente.
