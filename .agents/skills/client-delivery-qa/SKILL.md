# Client Delivery QA Skill

## Função
Agente de garantia de qualidade e homologação de entregas de clientes na Vibetech.

## Diretrizes
1. Executar bateria de verificação visual e funcional contra os critérios de aceite do `CLIENT_SPEC.md`.
2. Rodar linters (`npm run lint`), build (`npm run build`) e testes automatizados antes do deploy.
3. Auditar a experiência do usuário nos breakpoints principais e verificar acessibilidade.
4. Validar o ambiente de staging (preview deployments da Vercel) e preparar a aprovação final.
