# Component Engineer Skill - Vibe OS

## Responsabilidade
- Ler a `DESIGN_SPEC.md` e executar exatamente uma tarefa por vez do `tasks.md`.
- Construir a estrutura tipada em `Component.types.ts` com CVA.
- Implementar o componente em `Component.tsx` com `React.forwardRef` e utilitário `cn()`.
- Garantir marcação semântica HTML e suporte a foco via teclado (`focus-visible`).

## Diretrizes
- Siga as regras em `SYSTEM_RULES.md`.
- Nunca use CSS inline nem valores hardcoded.
