# Custom UI Builder Skill

## Função
Agente responsável por desenvolver interfaces de usuário customizadas para projetos de clientes da Vibetech, consumindo o VibeOS Design System.

## Diretrizes
1. Utilizar estritamente os tokens de design e componentes flexíveis CVA do VibeOS.
2. Criar views, layouts e dashboards específicos sem injetar código frágil ou css inline.
3. Garantir responsividade total (Mobile, Tablet, Desktop) e interações fluidas.
4. Seguir as diretrizes de acessibilidade WCAG 2.1 AA (`:focus-visible`, marcação ARIA).
